Network Ports & Service Architecture

A visual, beginner-friendly guide to how ports, servers, and AI verification connect.

🏢 The Apartment Building Analogy

Think of your computer as a large apartment building:
• Your IP Address (192.168.1.14 or 127.0.0.1) is the building's street address.
• Ports (80, 8000, 8001, 5173) are the individual apartment doors inside!
The Golden Rule: Only ONE program can live inside an apartment door at any time.

🚪 The Active Port Directory

80 Apache
XAMPP Web Server
Serves the Laravel dashboard in your browser when using http://firesight-web.test.
8000 Laravel CLI
Unified Mobile API
Listens for incoming requests from resident and BFP mobile phones via php artisan serve.
8001 Python AI
Fire Verification AI
Runs MobileNetV3 ONNX model via FastAPI to classify uploaded fire photos (fire / non-fire).
5173 Vite Dev
React Hot Reloading
Compiles React, TypeScript, and Tailwind CSS styles instantly as you make code changes.
3306 Database
MySQL Database
Stores all users, incident records, fire reports, and boundary polygons in firesight_db2.

🔍 The Mystery Solved: Why did it work before?

Timeframe Laravel Port AI Microservice Port Why there was no error
Before 80 (via Apache) 8000 (Python) You only ran npm run dev. Apache handled Laravel on Port 80, leaving Port 8000 free for Python!
Now 8000 (Artisan) 8001 (Python) The mobile app connects to Laravel on 8000, so Python was moved to 8001 to prevent conflicts.

📸 The Journey of a Fire Incident Photo

1

Resident Snaps & Submits Photo

The mobile app sends an HTTP POST with the photo to http://192.168.1.14:8000/api/reports.

2

Laravel Saves File & Forwards to AI

Laravel saves the image into storage/app/public/uploads/, then makes an internal cURL call to http://127.0.0.1:8001/predict.

3

Python AI Runs Neural Inference

FastAPI loads the image into fire_verification_model.onnx and responds: {"fire": true, "confidence": 0.97}.

4

Database Updated & Real-time Alert

Laravel saves the AI label and confidence into MySQL (Port 3306), and the incident instantly appears on the BFP Dashboard map!

🖥️ The 5 Essential Services That Must Run on the Server

1

Nginx Web Server & Reverse Proxy (Port 80 & 443)

Accepts public incoming web traffic with SSL/HTTPS certificates (Let's Encrypt / Certbot). Routes /api and web traffic to PHP-FPM.

2

PHP-FPM (FastCGI Process Manager)

Executes Laravel PHP code in the background without needing php artisan serve. High performance and multi-threaded.

3

MySQL / MariaDB Database (Port 3306)

Maintains persistent records for incidents, user accounts, barangay polygons, and fire risk assessment history.

4

Python AI Microservice (Systemd Service on Port 8001)

Managed via Linux Systemd (/etc/systemd/system/fire-verification.service) to auto-start on server boot and auto-restart on crashes.

5

Laravel Background Queue & Cron Worker (Supervisor)

Managed via Supervisor to run php artisan queue:work --tries=3 for async jobs and Linux crontab (* * * * * php artisan schedule:run) for daily duty shifts and risk calculations.

📋 Production Configuration Snippets (Copy & Paste)

A. Python AI Service Unit (/etc/systemd/system/fire-verification.service):

[Unit] Description=FireSight AI Fire Verification Microservice After=network.target [Service] User=www-data WorkingDirectory=/var/www/FireSight-Web/fire-verification-service ExecStart=/var/www/FireSight-Web/fire-verification-service/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8001 --workers 2 Restart=always RestartSec=3 [Install] WantedBy=multi-user.target

B. Laravel Queue Worker Unit (/etc/supervisor/conf.d/firesight-worker.conf):

[program:firesight-worker] process_name=%(program_name)s_%(process_num)02d command=php /var/www/FireSight-Web/artisan queue:work --sleep=3 --tries=3 --max-time=3600 autostart=true autorestart=true user=www-data numprocs=2 redirect_stderr=true stdout_logfile=/var/log/firesight-worker.log
